# sandbox/

Песочница для ручной проверки расширения Commiter. Содержимое не влияет на сборку
(`sandbox/` не исключён из репозитория специально — правь и коммить как угодно).

Сценарий проверки:

1. `git add sandbox/…` — проиндексировать изменения
2. Нажать кнопку-палочку справа в поле ввода сообщения коммита (панель «Система управления версиями»)
3. Дождаться сгенерированного текста в поле
