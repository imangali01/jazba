# 01: Каркас расширения + кнопка-палочка пишет заглушку в поле коммита

**What to build:** Пользователь ставит расширение, открывает панель Source Control и видит справа в поле ввода сообщения коммита кнопку-палочку. По клику (или через команду «Commiter: Сгенерировать сообщение коммита» в палитре) в поле коммита активного репозитория появляется текст-заглушка. Это доказывает, что расширение активируется, находит git-репозиторий и умеет писать в `inputBox`.

**Blocked by:** None (can start immediately).

**Status:** done (manual dev-host click pending user verification)

- [ ] Расширение активируется без ошибок в Extension Development Host
