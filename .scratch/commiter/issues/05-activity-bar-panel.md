# 05: Панель в Activity Bar (TreeView) + монохромная иконка

**What to build:** В левой полосе значков (рядом с Проводник / Поиск / Система управления версиями / Запуск и отладка) появляется значок Commiter. По клику открывается панель со списком: сгенерировать сообщение, текущий язык, текущий стиль, включено ли тело, открыть журнал. Клик по строке языка/стиля открывает выбор, строка тела переключается. Строки показывают актуальные значения настроек.

**Blocked by:** 04.

**Status:** done (v0.0.6) — контейнер Activity Bar + TreeView с 5 строками: Сгенерировать / Язык / Стиль / Длина / Открыть журнал. Клик открывает QuickPick, дерево обновляется по onDidChangeConfiguration. Монохромная иконка media/activity.svg (авто-тема). Выбор репозитория при нескольких — через resolveRepository (без отдельного QuickPick пока).

- [ ] `viewsContainers.activitybar` с монохромным SVG-значком (перерисовка `magit.jpg`: цилиндр + палочка + `+`/`−`), который следует теме как встроенные значки
- [ ] `views` содержит один TreeView; заголовки строк по-русски:
  - «✨ Сгенерировать сообщение коммита» → запускает `commiter.generate`
  - «Язык: <текущий>» → QuickPick Русский / English → пишет `commiter.language` глобально
  - «Стиль: <текущий>» → QuickPick авто / conventional / plain → пишет `commiter.commitStyle`
  - «Тело сообщения: вкл|выкл» → переключает `commiter.includeBody`
  - «Открыть журнал» → показывает output-канал «Commiter»
- [ ] Дерево обновляется при изменении конфигурации (`onDidChangeConfiguration`)
- [ ] Строка генерации в панели действует на активный/единственный репозиторий; при нескольких и неоднозначности — QuickPick выбора репозитория
- [ ] Провайдер дерева и формирование подписей строк покрыты юнит-тестами там, где логика чистая
