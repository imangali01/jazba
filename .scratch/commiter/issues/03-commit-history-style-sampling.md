# 03: Выборка стиля из истории коммитов

**What to build:** Сгенерированное сообщение повторяет стиль этого репозитория — время глагола, префиксы, регистр, длину. Расширение подмешивает в промпт примеры недавних коммитов, стараясь сбалансировать коммиты владельца репозитория и остальных авторов. В свежем репозитории без истории генерирует по разумным умолчаниям.

**Blocked by:** 02.

**Status:** done (v0.0.7) — collectExamples: git log --no-merges, split ≤perBucket владелец / ≤perBucket другие + добор до commiter.historyCount (20), трейлеры срезаются (stripTrailerLines), <3 → без секции примеров. Примеры идут в промпт с инструкцией «подражай стилю, не копируй». E2E проверено: auto+история → conventional-стиль на русском.

- [ ] Берётся `git log --no-merges` с автором и полным телом сообщения
- [ ] Выборка: до 10 самых свежих коммитов, где email автора == `git config user.email`, плюс до 10 самых свежих от других авторов; если ведро неполное — добор из другого до 20 всего; если `user.email` не задан — просто 20 самых свежих
- [ ] Из примеров вырезаются строки `Co-Authored-By:` и трейлеры ботов
- [ ] Меньше 3 пригодных коммитов → режим «нет истории»: примеры в промпт не идут, добавляется инструкция по умолчанию (императив, короткий заголовок)
- [ ] Примеры вставляются в промпт из тикета 02
- [ ] Чистые функции (парсинг лога, разбиение 10/10 с добором, детектор «нет истории», зачистка трейлеров) покрыты юнит-тестами `node:test`
- [ ] Ручная проверка: в репозитории со стилем Conventional Commits сгенерированное сообщение тоже в этом стиле
