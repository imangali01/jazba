# 02: Staged-дифф → `claude -p` → настоящее сообщение в поле

**What to build:** Пользователь делает `git add`, жмёт кнопку-палочку — расширение собирает staged-дифф, спрашивает у Claude текст коммита и вставляет его в поле сообщения. Виден отменяемый индикатор прогресса; при ошибке — понятное уведомление, детали — в output-канал «Commiter».

**Blocked by:** 01.

**Status:** ready-for-agent

- [ ] Собирается `git diff --staged --stat` (всегда целиком) плюс тело диффа, обрезанное до `commiter.maxDiffChars` (по умолчанию 4000) с маркером обрезки
- [ ] Если в staged ничего нет — предложение «Использовать все изменения?»; при отказе команда завершается тихо
- [ ] Промпт собирается чистой функцией и передаётся в `claude -p` через stdin; путь бинарника — `commiter.claudePath` (по умолчанию `claude`), доп. аргументы — `commiter.claudeExtraArgs` (по умолчанию `[]`)
- [ ] Вызов обёрнут в отменяемый `window.withProgress`; отмена или таймаут `commiter.timeoutSeconds` (по умолчанию 90) убивает дочерний процесс и показывает уведомление
- [ ] Вывод модели очищается: снимаются ```-ограждения, обрамляющие кавычки, лишние пустые строки
- [ ] Если в поле ввода уже есть текст — он передаётся в промпт как черновик/подсказка, затем поле перезаписывается результатом
- [ ] Output-канал «Commiter» логирует финальный промпт, stderr и код выхода
- [ ] Чистые функции (сборка промпта, обрезка диффа, очистка вывода) покрыты юнит-тестами; `npm test` зелёный
- [ ] Настройки `claudePath`, `claudeExtraArgs`, `timeoutSeconds`, `maxDiffChars` объявлены в `package.json`
